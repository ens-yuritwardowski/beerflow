# Resumo da Automação Proposta

O BeerFlow é um projeto desenvolvido para automatizar processos de uma cervejaria, facilitando o controle de pedidos, estoque, produtos, clientes e pagamentos.

A proposta busca reduzir tarefas manuais, melhorar a organização das informações e tornar o atendimento mais rápido e eficiente.
